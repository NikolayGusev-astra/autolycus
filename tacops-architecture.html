Tacops — Terraform + Ansible CoPilot

Automatic infrastructure stand deployment via Hermes Agent

Архитектура

  • • Tacops — плагин-оркестратор в plugins/tacops/
  • • Модели данных: StandSpec, VmSpec, BastionSpec, NetworkSpec
  • • Оркестратор: plan() → deploy() → destroy() → status()
  • • Поддержка OpenNebula (Proxmox заложен)
  • • Весь инструментарий в portable/ — без sudo

Ansible Фазы

  • • 01_bastion_setup — bind9, NAT, forwarding
  • • 02_infrastructure — CA, LDAP, DNS
  • • 03_aldpro_deployment — Domain Controller
  • • 04_keycloak_docker — Keycloak + SPNEGO
  • • 05_external_users — Kerberos
  • • 06_keycloak_test_app — тестовые приложения
  • • 10_smartcard_setup — SoftHSM2
  • • 12_smartcard_auth_test — проверка

Инструментарий

  • • portable/bin/terraform (musl, static)
  • • portable/bin/fd, rg — быстрый поиск
  • • portable/bin/gh — GitHub CLI
  • • portable/bin/jq, yq — процессоры JSON/YAML
  • • portable/venv/ansible-core — управление
  • • portable/venv/pyone — OpenNebula API
  • • Установка: bash portable/install.sh
