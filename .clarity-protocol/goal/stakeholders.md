# Stakeholder Analysis — PGB Law AI Lawyer System

## Классификация по осям: Влияние (Direct/Indirect) × Отношение (Aligned/Adversarial)

---

## Прямые стейкхолдеры (Direct)

### 1. Управляющий партнёр (Голотвин С.А.) — Aligned
- **Роль:** Заказчик проекта, финальное решение по бюджету и стратегии
- **Интересы:** Окупаемость инвестиций, репутация Бюро, контроль над системой
- **Критические требования:** Безопасность данных, соблюдение адвокатской тайны, результат
- **Побою:** Утечка данных → потеря лицензии и клиентов

### 2. Кураторы (партнёры и адвокаты Бюро) — Aligned
- **Роль:** Основные пользователи системы (создание дел, постановка задач, приёмка результатов)
- **Интересы:** Экономия времени, качество результатов, удобство интерфейса
- **Критические требования:** Работающий Intake-протокол, понятные чек-листы, прозрачные источники
- **Потенциальный конфликт:** Куратор не юрист-техie — интерфейс должен быть максимально простым
- **Побой:** Система «выдумает» практику → Куратор подписывает → ответственность на Кураторе

### 3. Помощники Куратора — Aligned
- **Роль:** Загрузка документов, выгрузки из КонсультантПлюс, ввод первичных данных
- **Интересы:** Минимум ручных операций, понятные инструкции
- **Критические требования:** Простой интерфейс загрузки, автоматическая индексация
- **Побой:** Ручная выгрузка из КП станет bottleneck'ом при нагрузке

### 4. Подрядчик (разработчик) — Aligned, с элементами Adversarial
- **Роль:** Реализация системы
- **Интересы:** Фиксированный бюджет, минимизация scope creep, повторные заказы
- **Критические требования:** Чёткое ТЗ, контрольные точки
- **Потенциальный конфликт:** Подрядчик может предложить «упрощения», которые снижают безопасность
- **Побой со стороны PGB Law:** Vendor lock-in

## Непрямые стейкхолдеры (Indirect)

### 5. Клиенты PGB Law (включая Forbes) — Indirect / Aligned
- **Влияние:** Крайне высокое — при утечке теряют деньги, репутацию, свободу
- **Интересы:** Качественная юридическая помощь, конфиденциальность
- **Уязвимость:** Не знают об использовании ИИ, не дали согласия на обработку данных AI
- **Критический момент:** Действие адвокатской тайны — согласие клиента на использование ИИ не требуется (но требуется обеспечение конфиденциальности)

### 6. Оппоненты клиентов PGB Law — Indirect / Adversarial
- **Интересы:** Могут попытаться получить информацию о стратегии, фактуре через внешние сервисы
- **Уязвимость:** Нет
- **Риск:** Если система допустит утечку — противоположная сторона может использовать

### 7. ФНС, судебная система, регуляторы — Indirect / Aligned/Neutral
- **Интересы:** Соблюдение законодательства об адвокатской тайне
- **Уязвимость:** Нет — это regulatory stakeholder
- **Риск:** При нарушении — проверки, лишение лицензии

### 8. Вендоры (Anthropic/Claude API, КонсультантПлюс, Casebook) — Indirect / Aligned
- **Интересы:** Продажа сервисов, соблюдение ToS
- **Риск:** При нарушении условий (парсинг, headless browser, извлечение БД) — блокировка аккаунта

## Скрытые стейкхолдеры (identified during analysis)

### 9. Сотрудники Бюро, не работающие с системой — Indirect / Aligned
- **Интересы:** Их персональные данные и дела должны быть недоступны другим сотрудникам без разрешения
- **Требование ТЗ:** «Один Куратор не видит дел другого без явного разрешения» (§5.1)

### 10. Будущие клиенты (потенциальные) — Indirect / Aligned
- **Интересы:** Их данные на стадии Intake защищены (§12.2 Конституции: «Адвокатская тайна с момента обращения»)
