## Autolycus v0.1.2 — Enterprise AI Assistant

Релиз на базе Hermes Agent v0.13.0 с добавлением корпоративных плагинов и улучшений безопасности.

### Что нового

**🔒 SBL (System Boundary Layer)** — детерминированный FHS-классификатор на уровне tool call dispatch. Перехватывает write_file/patch/terminal, классифицирует пути (SYSTEM/USER/UNKNOWN), снимает снапшот инфраструктуры (systemctl, порты, процессы), проверяет зависимости. Без LLM на critical path. Deep audit через fd/rg: FMC (Find, Map, Collect), извлечение портов/доменов/сертификатов.

**🛡️ Ultra Governance** — Policy Engine с 4 режимами (off/audit/simulate/enforce) + Governance Coordinator. Deny-list, allow-list, param rules, max param bytes. 18 E2E тестов с реальной политикой и SBL классификацией.

**⚡ RTK v2 (Reduced Token Kernel)** — недеструктивный компрессор tool output. Head/tail truncation, repeat compaction, type-aware per-tool стратегии. Bounded buffer + circuit breaker + pattern detection (CONSECUTIVE_ERRORS, TOOL_LOOP, BUDGET_EXCEEDED, NO_PROGRESS) + signal injection. Сохранение ~84% токенов. Recovery через rtk_recover. 56 тестов, 31/31 pass.

**🏗️ Tacops** — Terraform + Ansible CoPilot. Автоматическое развёртывание тестовых стендов на OpenNebula. Модели: StandSpec, VmSpec, BastionSpec. 8 Ansible фаз (bastion → infrastructure → aldpro → keycloak → external_users → keycloak_apps → smartcards → smartcard_test). Весь инструментарий в portable/ (musl бинарники: terraform, fd, rg, gh, jq, yq; venv: ansible-core, pyone).

**📄 Doc Session** — создание многостраничных документов через section-based запись. file_doc_create/write/finalize. Три уровня защиты от write_file для больших документов.

**🧠 ContextWriter** — rebuild памяти: все-туры логирование, rg fallback, config.yaml window_size, shutdown hook, findings_to_wiki без LLM.
