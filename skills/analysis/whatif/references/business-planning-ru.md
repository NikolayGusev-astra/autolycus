## Регистрация товарного знака (ТЗ) в РФ

**Проверка:** ФИПС не имеет открытого API. Проверять через SPA-форму в браузере:
- searchplatform.rospatent.gov.ru
- poisk.fips.ru
Выбрать раздел «Товарные знаки», ввести название, проверить классы МКТУ 9 и 42.

**Регистрация:**
- Этап 1: Подача заявки (пошлина ~3 500 ₽ за 1 класс МКТУ)
- Формальная экспертиза: 1-2 мес
- Экспертиза по существу: 6-12 мес
- Регистрация: +2 мес (~16 200 ₽ пошлина)
- **Итого:** ~10-14 мес, ~21 000-25 000 ₽
- **Важно:** дата приоритета — по дате подачи заявки. Защита с первого дня.

**Классы МКТУ для AI/IT:**
- Класс 9 — ПО, программы, AI-платформы (базовый)
- Класс 42 — Разработка ПО, IT-консалтинг (базовый)
- Класс 38 — Телекоммуникации (опционально)

**Стратегия:** подавать заявку сразу после регистрации юрлица. 25k — небольшая плата за защиту имени.

## Регистрация ИП

**Через Госуслуги:** бесплатно (без госпошлины), 3 дня.
**Через Тинькофф:** 0-4 000 ₽, 1-3 дня, сразу открывается р/с.

**ОКВЭД:**
- 62.01 — разработка ПО (основной)
- 62.02 — консультационные услуги
- 62.09 — прочее

**Налоги:**
- УСН 6% (доходы) — оптимально, квартальная отчётность
- НПД (самозанятость) — 4-6%, без отчётности, лимит 2.4 млн/год

**После регистрации:**
- Расчётный счёт (Тинькофф Бизнес — бесплатно первый год)
- Электронная подпись (1 500-3 000 ₽, нужна для договоров с enterprise)
- Бухгалтерия (Эльба / Тинькофф — 0-1 000 ₽/мес)

## Партнёрства

**Структуры:**
1. **ООО (два учредителя 50/50):** солиднее для enterprise, нужен уставной капитал 10k, бухгалтерия
2. **Ты ИП + партнёр самозанятый по агентскому договору:** просто, продукт твой, партнёр получает % со сделок
3. **Оба ИП + договор простого товарищества:** 50/50, гибко, но enterprise не любят

**IP Agreement (критично!):**
До написания кода подписать:
- Кому принадлежит базовая платформа
- Кому принадлежат кастомизации под клиента
- Что происходит при расставании
- Достаточно письменной формы (Telegram — юридически значимо)

## Enterprise-readiness для РФ

Для продажи банкам/enterprise через Ассоциацию ФинТех:
- Selectel VPS (РФ) — решает 80% вопросов ФЗ-152
- DPA (Data Processing Agreement) — шаблон из Тинькофф/Сбера
- Уведомление РКН — подаётся онлайн бесплатно, если обрабатываете ПД
- Типовой договор + счёт + акт — подготовить заранее
- Сертификация ФСТЭК — **не нужна** для банков/enterprise на этапе пилота, нужна для ОГВ
